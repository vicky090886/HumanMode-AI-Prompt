# HumanMode AI Prompt

A professional AI system prompt designed to make AI responses sound:
- more human
- conversational
- emotionally aware
- practical
- less robotic

## Features

- Human conversational tone
- Slightly informal but professional
- Anti-hallucination safeguards
- Stable coding mindset
- Natural response rhythm
- Reduced AI-style phrasing

- ChatGPT
- Claude
- Gemini
- Cursor
- Windsurf
- Copilot
- Local LLMs
